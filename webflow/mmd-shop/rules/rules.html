01 ราคาและสต๊อก

ราคาบน MMD Shop คือราคาของ MMD Shop และก่อนเปิด Order เราจะเช็กราคาอีกครั้งจากรายการจริงครับ

เมื่อสต๊อกจริงยืนยันพร้อม ปุ่มสั่งจะเปิดทันที เพื่อให้ทุก Order เริ่มจากของจริง

สินค้าที่ระบุ On-demand จะเปิด Checkout เมื่อ Supplier ที่ MMD ยืนยันพร้อม และสถานะพร้อมส่งจะเริ่มเมื่อ Order เข้าสู่ขั้นตอนเตรียมสินค้า

บางชิ้นเปิดให้ดูรายละเอียดล่วงหน้า และปุ่ม Online Checkout จะพร้อมตามสถานะบนหน้าสินค้านั้นครับ

02 การชำระเงินและสลิป

ให้ชำระจากลิงก์ของ Order นั้นโดยตรง ยอดที่ใช้จริงคือยอดบน Order ครับ

ส่งสลิปครั้งเดียวพอ สลิปที่ส่งเข้ามาหมายถึง “ได้รับหลักฐานแล้ว” และจะถือว่าชำระสำเร็จเมื่อ MMD ตรวจยอดเรียบร้อยเท่านั้น

03 การเตรียมและรับสินค้า

หลังยืนยันยอดแล้ว MMD จะเตรียมของตาม Order เดิม วิธีรับสินค้าและเลขติดตามจะผูกอยู่กับรายการนั้นครับ

ถ้าการจัดส่งต้องดูแลต่อ เราจะอัปเดตสถานะบน Order เดิมให้ครบ

04 คืนสินค้าและคืนเงิน

ถ้ามีเคส Return หรือ Refund จะเดินต่อจาก Order เดิม เพื่อให้ตามเรื่องได้จากรายการเดียว

สถานะคืนเงินจะแสดงเมื่อ MMD บันทึกการคืนเงินจริงแล้ว โดยยึดข้อมูลที่ยืนยันในระบบเป็นหลักครับ

\n
05 ถ้าติดตรงไหน

ส่ง Order ID มาให้ MMD ได้เลยครับ เราจะเปิดรายการเดิม ตรวจยอด และดูแลหน้าชำระต่อจากจุดนั้น
