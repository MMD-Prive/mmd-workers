ชำระเงินให้ตรงรายการ

กติกาหน้านี้อธิบายสิ่งที่ระบบ MMD ใช้จริงในการสร้าง Order ตรวจราคา รับหลักฐานการชำระเงิน และอัปเดตสถานะรายการ

01ราคาและรายการสินค้า

ราคาที่เห็นบนหน้า MMD Shop เป็นราคาจาก MMD Shop catalog และระบบจะตรวจราคาอีกครั้งจากฝั่งเซิร์ฟเวอร์ก่อนสร้าง Order ทุกครั้ง

เฉพาะสินค้าที่สถานะพร้อมขายและเปิดสำหรับ MMD Shop เท่านั้นที่สามารถสร้าง Online Order ได้

02การชำระเงิน

Order จะพาไปยัง MMD Payment surface ที่ระบบสร้างให้กับรายการนั้นโดยตรง ยอดใน browser ไม่ใช่ authority ในการยืนยันเงิน

สลิปหรือหลักฐานที่อัปโหลดคือหลักฐานเพื่อรอตรวจเท่านั้น รายการจะเปลี่ยนเป็นชำระแล้วหลังผ่าน Official Verification ของ MMD

03ส่งหลักฐานครั้งเดียว

เมื่อส่งหลักฐานผ่านหน้าชำระเงินของ Order แล้ว ไม่จำเป็นต้องส่งหลักฐานเดิมซ้ำอีกครั้ง ระบบจะแสดงสถานะรอตรวจจนกว่าจะมีผลยืนยัน

หากไม่สามารถส่งผ่านเว็บได้ สามารถติดต่อ MMD เพื่อขอความช่วยเหลือได้ โดยการติดต่อไม่ทำให้รายการถูกถือว่าชำระแล้วอัตโนมัติ

04สต๊อกและการเตรียมสินค้า

สินค้าที่มีสต๊อกแบบติดตามจะถูกตรวจจำนวนก่อนสร้าง Order หากจำนวนไม่พอ ระบบจะไม่รับ Checkout สำหรับจำนวนนั้น

บางรายการอาจอยู่ในสถานะที่ต้องยืนยันสต๊อกก่อนจัดรายการ รายละเอียดการรับหรือจัดส่งจะยืนยันกับ Order นั้นตามข้อมูลที่ MMD แจ้ง

05สินค้าที่ไม่เปิด Online Checkout

บางรายการอาจแสดงเพื่อให้ดูรายละเอียด แต่ไม่เปิดให้สร้าง Online Order ระบบจะซ่อนปุ่มซื้อและไม่รับ Checkout สำหรับสินค้ากลุ่มนั้น

ให้ยึดสถานะบนหน้าสินค้าและคำยืนยันจาก MMD เป็นหลัก

07ต้องการความช่วยเหลือ

หากเปิด Order ไม่ได้ ยอดไม่ตรง หรือหน้าชำระเงินมีปัญหา ให้ติดต่อ MMD พร้อม Order ID เพื่อให้ตรวจรายการเดิม ไม่ควรสร้าง Payment ซ้ำเพื่อแก้ปัญหาเอง
