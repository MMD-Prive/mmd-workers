01 ราคาและสต๊อก

ราคาบน MMD Shop คือราคาของ MMD Shop และก่อนเปิด Order เราจะเช็กราคาอีกครั้งจากรายการจริงครับ

สินค้าที่ใช้สต๊อกจริง ถ้าสต๊อกยังไม่ยืนยันหรือของไม่พอ ปุ่มสั่งจะไม่เปิดให้กด เพื่อไม่ให้รับเงินก่อนรู้ว่ามีของจริง

สินค้าที่ระบุ On-demand เป็นอีกกรณี: ระบบจะเปิด Checkout ได้เมื่อมี Supplier ที่ MMD ยืนยันไว้ แต่ยังไม่ถือว่าเป็นสต๊อกพร้อมส่งจนกว่า Order นั้นจะเข้าสู่ขั้นตอนเตรียมสินค้า

บางชิ้นอาจมีไว้ให้ดูรายละเอียด แต่ยังไม่เปิด Online Checkout ให้ยึดปุ่มและสถานะบนหน้าสินค้านั้นเป็นหลักครับ

02 การชำระเงินและสลิป

ให้ชำระจากลิงก์ของ Order นั้นโดยตรง ยอดที่ใช้จริงคือยอดบน Order ครับ

ส่งสลิปครั้งเดียวพอ สลิปที่ส่งเข้ามาหมายถึง “ได้รับหลักฐานแล้ว” และจะถือว่าชำระสำเร็จเมื่อ MMD ตรวจยอดเรียบร้อยเท่านั้น

03 การเตรียมและรับสินค้า

หลังยืนยันยอดแล้ว MMD จะเตรียมของตาม Order เดิม วิธีรับสินค้าและเลขติดตามจะผูกอยู่กับรายการนั้นครับ

ถ้าการจัดส่งมีปัญหา เราจะอัปเดตสถานะเดิม ไม่ต้องสร้าง Order ใหม่เอง

04 คืนสินค้าและคืนเงิน

ถ้ามีเคส Return หรือ Refund จะเดินต่อจาก Order เดิม เพื่อให้ตามเรื่องได้จากรายการเดียว

สถานะคืนเงินจะแสดงเมื่อ MMD บันทึกการคืนเงินจริงแล้ว ไม่ใช้ข้อความหรือสลิปเป็นตัวเดาแทนครับ

\n
05 ถ้าติดตรงไหน

ถ้ายอดไม่ตรง เปิด Order ไม่ได้ หรือหน้าชำระมีปัญหา ส่ง Order ID มาให้ MMD ดูรายการเดิมได้เลยครับ ไม่ต้องสร้าง Payment ซ้ำ
