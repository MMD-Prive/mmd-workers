# MMD Acquisition + PR / Hiring Plan — 2026-09-29

## Goal

Turn the newly stabilized MMD APP / Job Board / Studio / Kenji stack into a real acquisition loop for Models, Travel Models, and public/private member interest without launching APP/SIGIL always-on before the final production gates pass.

## Operating order

1. Use Public Job Board recruitment as the first model acquisition lane.
2. Use Travel Model preview content as the public-facing hook.
3. Use X / Fanpage / IG for awareness, then route interested Models to the MMD APP Welcome / LINE LIFF path.
4. Use Studio My Card only after real Model media is approved.
5. Keep SIGIL/APP always-on campaign disabled until the final handoff + campaign destination gates pass.

## Weekly targets

| Lane | Target | Evidence |
| --- | ---: | --- |
| New Model leads from Job Board | 20 / week | Click → LINE/LIFF → onboarding start |
| Completed Model onboarding | 5 / week | verified_new or existing_bound |
| Approved public media sets | 3 / week | 8 public photos + 2 clips, public_safe=true |
| Studio card drafts | 3 / week | generated draft + owner review |
| Travel Model preview posts | 3 / week | Telegram preview or public social post URL |
| Public member leads | 15 / week | MY MMD login / membership intent |

## Content lanes

### 1. Model recruitment post

Purpose: find men who are open to MMD work and ready to enter MMD APP.

CTA: open MMD APP / Job Board. Do not promise guaranteed jobs, rates, or acceptance.

Core copy angle:

> มีงานเปิดรับจริงใน MMD APP  
> ถ้าคุณเหมาะกับงาน ระบบจะพาไปกรอกข้อมูลและส่งรูปให้ Studio ตรวจ  
> สมัครเพื่อให้ MMD พิจารณา ไม่ใช่การรับงานอัตโนมัติ

### 2. Travel Model preview

Purpose: make public audience curious without exposing private/SIGIL content.

Rules:
- Use MMD Privé public visual system, not SIGIL.
- No private/pending media.
- No client-identifying detail.
- No rate promises unless owner approved.
- Route to LINE/MY MMD/Job Board depending on audience.

### 3. Public member acquisition

Purpose: move non-members to Public Membership / MY MMD.

CTA: MY MMD login or Public Membership.

Copy must avoid saying verification itself creates extra entitlement unless currently true in resolver.

### 4. Kenji concierge ad

Purpose: let new users ask before committing to LINE/Telegram.

Route: `/concierge/kenji`.

Message:
- Thai / English / Chinese supported.
- Ask initial questions first.
- Membership/payment/booking/private profile answers require verified MMD system truth.

## Guardrails

- Do not enable APP/SIGIL always-on campaign until final gates are pass.
- Do not use private/SIGIL media in public acquisition.
- Do not auto-bind a Model from a lead.
- Do not promise rate, job, acceptance, membership, or payment confirmation in ad copy.
- Use LINE OFC snapshots first when historical truth is needed.
- Keep customer identifiers out of public posts.
