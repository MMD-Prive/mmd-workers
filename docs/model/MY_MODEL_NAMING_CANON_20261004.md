# MY MODEL naming canon — 2026-10-04

Owner approved renaming the MMD worker app from MMD APP to MY MODEL.

| Audience | MMD | MMS |
| --- | --- | --- |
| Customers | MY MMD | MY MMS |
| Workers | MY MODEL | MY THERAPIST |

MY MODEL includes the existing Public MMD Privé and Private SĪGIL worlds. The private brand remains SĪGIL. MMD APP in earlier documents is the historical name of MY MODEL.

This is a presentation and notification-copy rename. Existing LINE LIFF IDs, links, routes, API contracts, authentication cookies, worker names, role/access rules, payment and payout calculations stay unchanged. Technical identifiers containing mmd_app or my_mms_access are compatibility identifiers, not product naming authority.

Repository changes cover native app pages, PWA manifest, worker notification templates and versioned Webflow navigation/worker-facing copy, including the Wish paste-ready source. Updating repository Webflow snippets does not prove they have been pasted and published. LINE Developers app display names, OA display names and existing rich-menu image artwork require their own publication; this change does not claim those external settings are updated.
