MMD PRIVÉ / CORE RULES

What to understand before entering

These rules are not here to make access difficult. They exist so every step stays clear, safe, private, and traceable.

01

Privacy First

Personal information, conversations, photos, contact details, and service-related activity must be handled carefully inside a private system. MMD does not push sensitive details into personal social media spaces.

02

Respect & Boundaries

Respect and clear boundaries are basic rules. If something is unclear, it must be asked and confirmed first. Guessing should never replace direct communication.

03

No Drugs Policy

MMD does not support work involving drugs in any form. If a request appears risky or does not align with this rule, the process may be declined or stopped immediately.

04

Clarity Before Action

Every step should continue only when there is enough clarity, whether it involves access, identity confirmation, information submission, or use of a private system page.
